## Principles

1. Free to download and use, forever. No subscriptions or paid tiers.
2. Open source under an OSI-approved license (MIT by default).
3. No accounts, ads, telemetry or data collection.
4. Works offline. No network connection unless the feature needs one, and then only to the service the user chose.
5. Light on CPU, memory and battery. Performance is measured, not claimed.
6. Clear privacy policy and honest limitations for every tool.
